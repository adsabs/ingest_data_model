# ingest_data_model

This repository contains the draft schema for metadata import, to provide
a consistent input model for our eventual storage model.

Update, 2026 November 13: this repository has been reset to make the v1.0.12 release the new main branch head, with updates for the development versions of SciXIngestParser and SciXFulltextParser moved to a separate branch: dev_v1.1.  The dev_v1.1 branch contains the repository's previous main head commit prior to the reset.
